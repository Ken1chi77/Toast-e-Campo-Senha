# Toast e Campo Senha

Aluno: Enzo Kenichi Barbosa Higa

## Sobre o projeto
Aplicativo Android desenvolvido em Kotlin com layout XML, como parte de uma atividade realizada em sala de aula.

O aplicativo possui campos para digitar e-mail e senha e um botão "Entrar". Ao clicar no botão, os dados digitados são exibidos na tela por meio de uma mensagem Toast.

## Tecnologias utilizadas
- Kotlin
- Android Studio
- XML
- Gradle
- View Binding

## Funcionalidades
- Campo para digitar o e-mail
- Campo para digitar a senha
- Botão para exibir os dados digitados
- Exibição das informações usando Toast

## Como executar
1. Clone ou baixe este repositório do GitHub.
2. Abra o Android Studio.
3. Clique em **Open** e selecione a pasta do projeto.
4. Aguarde a sincronização do Gradle terminar.
5. Execute o aplicativo em um emulador Android ou em um dispositivo físico conectado ao computador.
6. Digite um e-mail e uma senha nos campos correspondentes.
7. Clique no botão **Entrar** para visualizar os dados digitados.

## Exemplo de exibição
```
Email: exemplo@teste.com
Senha: 123456
```
